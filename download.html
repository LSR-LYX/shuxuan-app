1 在手机上打开 App 安卓 / 苹果都行

手机浏览器扫码，或直接访问：
https://lsr-lyx.github.io/shuxuan-app/

2 方式 A：添加到主屏幕（最简，免打包）

  1. 用手机浏览器（Chrome / Edge / 夸克等）打开上面的链接
  2. 点浏览器菜单 ⋮ → 选择 「添加到主屏幕」/「安装应用」
  3. 桌面就会出现「树与璇」图标，点开就是全屏 App，还能离线使用

3 方式 B：打包成 APK 安装（真正的安装包）

  1. 电脑打开 https://www.pwabuilder.com（微软官方，免费）
  2. 在输入框粘贴上面的 App 链接，点 Start
  3. 点 Package for stores → 选 Android → Download
  4. 下载得到 xxx.apk，传到手机点击安装即可（首次需允许"安装未知应用"）
💡 注意：PWA Builder 打包时需要站点在公网可访问（已满足）。打包出的 APK 是正式安装包，可以分享给树宝一起装。
